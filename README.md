# 파이썬 머신러닝 완벽 가이드 - 학습 가이드

이 문서는 **파이썬 머신러닝 완벽 가이드** 교재의 핵심 내용을 챕터별로 정리한 학습 자료입니다.  
각 챕터의 핵심 개념, 코드 패턴, 학습 포인트를 빠르게 파악할 수 있도록 구성했습니다.

## 전체 학습 흐름

```
데이터 준비          모델링              고급 기법
──────────────      ────────────────    ────────────────────
1장 NumPy/Pandas →  2장 ML 입문     →   4장 분류/앙상블
                    3장 모델 평가    →   5장 회귀
                                        6장 차원 축소
                                        7장 클러스터링
                                        8장 NLP
                                        9장 추천 시스템
```

## 주요 라이브러리

| 라이브러리 | 용도 |
|-----------|------|
| `numpy` | 수치 연산, 배열 처리 |
| `pandas` | 데이터프레임, 데이터 전처리 |
| `scikit-learn` | 머신러닝 알고리즘 전반 |
| `xgboost` | 그래디언트 부스팅 (빠르고 강력) |
| `lightgbm` | 경량 그래디언트 부스팅 |
| `matplotlib` / `seaborn` | 데이터 시각화 |
| `nltk` / `gensim` | 자연어 처리 |
| `surprise` | 추천 시스템 |
